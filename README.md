# Hallucination Detection - SMILES 2026

This repository contains my solution for the SMILES-2026 Hallucination Detection technical project.

## Files

- `aggregation.py`: final feature extraction and aggregation method
- `probe.py`: default probe classifier
- `splitting.py`: default data splitting strategy
- `solution.py`: official pipeline used to run the solution
- `results.json`: results generated by `solution.py`
- `SOLUTION.md`: full report describing the method, experiments, and reproducibility instructions
